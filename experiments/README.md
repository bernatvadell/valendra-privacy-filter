# Experiments

The generated `runs/` directory is ignored. Use separate output directories and matching data/protocol configurations for causal and bidirectional models. Evaluation reports include a manifest fingerprint and protocol fingerprint. `smoke-results.md` records a deliberately tiny pipeline verification, not a trained production model or a generalization claim.

The [interim checkpoint-3,000 comparison](interim-validation-checkpoint3000.md) records a small synthetic validation sample across Valendra, OpenAI and NVIDIA models; it is not a final held-out evaluation.
